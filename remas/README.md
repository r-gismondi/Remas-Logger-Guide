# Remas Payload Guides

This folder is split by payload/network structure.

| Folder | Purpose |
|---|---|
| `DP_STRUCT` | Existing RemasLogger / `remas_struct` manuals for `DP_STRUCT` UDP and serial Remas output. |
| `TCS_STRUCT` | TCSLogger / `tcs_diagnostic_struct` manuals for `TCS_STRUCT` UDP and serial TCS diagnostic output. |
| `IBS_STRUCT` | MTIBS telegram / GenSheet tag-pattern guides. |

Start with `DP_STRUCT/README.md` for RemasLogger version lookup, or `TCS_STRUCT/README.md` for TCSLogger.
