# Remas Payload Guides

This folder is split by payload/network structure.

| Folder | Purpose |
|---|---|
| `DP_STRUCT` | Existing RemasLogger / `remas_struct` manuals for `DP_STRUCT` UDP and serial Remas output. |
| `IBS_STRUCT` | Placeholder for future IBS structure guides. |

Start with `DP_STRUCT/README.md` for the current RemasLogger version lookup.
